# 宝可梦发现室 · 立项报告与项目说明

## 一句话介绍

给刚接触宝可梦角色与属性规则的我和愿意试玩的同学，一个基于初代 151 只宝可梦公开资料的发现室：查图鉴、比较能力、试验属性倍率，在 3000 点预算内搭配六人队伍，并与参考队伍比较取舍。

## 内容主题

主题是宝可梦角色资料与规则探索。具体处境是：初学者认识一些动画或游戏角色，却不清楚它们的属性和能力差异；挑选喜欢的角色组成队伍时，也看不出属性重复与共同弱点。配队时设置明确预算，引导用户在成员能力、属性分布和防御弱点之间做取舍。

第一版限定全国图鉴编号 001—151 的默认形态，使用 PokéAPI 快照中的现行属性和基础能力。“初代”限定收录范围，不表示采用第一世代游戏的旧属性规则。内容的阅读价值是理解角色资料，交互价值是通过比较、组合和即时反馈学习规则。作品用于课程学习，与 Pokémon 官方无关联，角色与素材权利属于各自权利人。

## 目标用户

1. **我本人**：作为前端课程学生，学习数据整理、筛选排序、DOM 交互、表单校验和本地存储，也从零了解宝可梦资料。
2. **愿意试玩的同学**：从认识的角色开始探索，用图鉴寻找相似角色，在预算内搭配队伍，再与作者设计的参考队伍比较。

计划在课堂或课后邀请同学试玩，记录他们看不懂的术语、找不到的入口和操作反馈。目前没有开展问卷，也没有真实访问量或调研结论。演示账号仅展示不同用户的数据隔离，不代表真实参与者。

## 数据来源与形态

- 结构化资料：[PokéAPI 数据仓库](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)。整理角色、中文名、属性、六项基础能力和属性关系表。
- 角色图片：[PokéAPI sprites 仓库](https://github.com/PokeAPI/sprites)，保存为本地素材。
- 字段和单位：[PokéAPI v2 文档](https://pokeapi.co/docs/v2)。原始身高以分米、体重以百克记录，界面转换为米和千克。
- 规模：151 只默认形态、18 类常规属性、6 项能力。采集日期、版本、文件摘要写入 `assets/data/source-manifest.json`。

| 形态 | 字段 | 用途 |
|---|---|---|
| 编号与文本 | 编号、中文名、英文标识 | 检索和辨认角色 |
| 分类与关系 | 单/双属性、属性倍率 | 筛选、实验和队伍分析 |
| 数值 | 身高、体重、HP、攻击、防御、特攻、特防、速度 | 单位转换、排序与对比 |
| 图片 | 本地角色插画 | 图鉴卡片和详情 |
| 参考组合 | 作者编排的成员编号、主题与说明 | 提供可比较的静态挑战内容，公开角色参数保持原样 |
| 个人记录与时间 | 收藏、队伍、备注、创建/修改时间、练习成绩 | 保存实际操作产生的探索记录 |

基础能力和属性关系不凭空编造。能力条表示基础值，不是具体等级下的实战数值。队伍分析统计成员属性与防御弱点，不预测完整战斗胜率。

### 配队挑战规则

- 每支队伍最多 6 只，配队成本为每位成员六项基础能力的总和，队伍预算为 **3000 点**。3000 是本项目设计的挑战规则，不是官方比赛规则；可以根据实际试玩反馈调整，PokéAPI 原始能力值不随预算改变。
- 编辑时显示已使用与剩余点数，超出预算的新增成员和队伍保存会被阻止。已有的旧超预算队伍保留，可载入后调整；包含超预算队伍的备份导入会整体拒绝，校验通过前不覆盖当前记录。
- 参考队伍是作者设计的静态组合，与“我保存的队伍”分开展示。它们不代表真实玩家、在线协作或战绩。
- 当前编辑队伍可以与参考队伍或本人保存的队伍比较：成员数量、总成本与预算、六项基础能力平均值、成员属性分布，以及各攻击属性下的弱点/抵抗人数。不同人数的队伍不能只凭合计下结论；比较用于理解取舍，不判胜负，也不计算胜率。
- 页面提供一个明确的配队任务：当前编辑队伍需要 **6 位不重复成员、总成本不超过 3000 点、面对电属性攻击时的弱点成员不超过 2 位**。增删或载入成员后实时检查各项条件，电弱点指属性防御倍率大于 1。这是额外的练习目标，不改变一般队伍的保存规则；完成时不会自动保存队伍或成绩，也没有奖励、胜负与排名。

### 新手说明

页面内的折叠说明解释六项基础能力：HP 与可承受伤害有关；攻击、防御分别对应物理方向的输出与承受能力；特攻、特防分别对应特殊方向的输出与承受能力；速度通常影响行动先后。图鉴展示的是用于比较角色设定的基础值，实际能力还受等级等因素影响，不能直接把能力条当成对战结果。

属性防御倍率大于 1 表示弱点，小于 1 表示抵抗，等于 0 表示免疫；本项目统计的抵抗人数包含免疫成员。双属性的防御倍率相乘，例如 2 × 0 = 0。配队预算只把六项基础值相加作为成本，帮助初学者理解“能力与名额有限，需要取舍”，不代表官方规则或实战强弱评价。

### 属性实验室

左侧属性小精灵代表这次发射的单一攻击属性，右侧从本地图鉴中选择一只宝可梦。防御属性自动取自该角色资料，不手动拼出角色并不具备的属性组合。点击发射后，显示属性倍率和简短台词，并用火花轻跳、泡泡盾、轻晃或攻击散落分别表达弱点、抵抗、普通效果与免疫；计算过程放在可展开的说明中。

手动更换攻击属性或目标会回到准备状态，也可以用“一键试试”直接播放预设组合。选择与播放状态只留在内存，动效不参与倍率计算，也不会形成战斗记录。下方保留独立的 5 题属性练习；登录用户完成后保存现有成绩。实验发射无需先猜答案，不涉及血量、招式库或完整战斗。

## 功能清单

### 单机版本（必做）

- **图鉴探索**：搜索中文名、英文名或编号；按属性筛选，按编号、能力总和、身高、体重排序。
- **角色详情**：图片、属性、单位换算、六项基础能力、防御属性倍率。
- **新手说明**：通过页面内折叠内容理解六项基础能力、基础值与实际能力的区别、弱点/抵抗/免疫，以及预算含义。
- **能力对比**：最多同时比较 3 只角色。
- **属性实验**：让属性小精灵向选定的真实图鉴角色发射单一属性攻击，自动读取目标的单/双属性，以动效和台词显示倍率；可展开查看相乘过程，另有 5 题练习与登录成绩记录。
- **本地登录**：演示账号与本地注册账号各自保存收藏、队伍、练习记录。
- **个人收藏**：收藏角色，形成个人图鉴。
- **预算配队**：在 3000 点预算内添加/移除最多 6 位成员，查看剩余预算、属性分布、共同弱点和抵抗；保存、修改、删除个人队伍。
- **单一配队任务**：基于当前编辑队伍，实时检查“6 位不重复成员、预算内、电弱点人数不超过 2 位”三项条件；完成提示不自动保存成绩或队伍，不设置奖励与胜负。
- **参考队伍与比较**：浏览作者设计的静态挑战组合；将当前编辑队伍与参考队伍或本人保存的队伍并排比较，观察成本、六项能力平均值、属性分布和防御弱点/抵抗人数。
- **个人备份**：导出 JSON，完整校验后导入当前账号；超预算队伍等不合规内容会使整次导入失败，不部分写入。
- **独立运行**：资料与图片随项目保存，持久化集中于独立数据访问层。

### 网络版本（可选）

- 服务端认证与跨设备同步。
- 分享队伍、查看其他用户公开队伍。
- 基于真实用户提交的交流与反馈。

筛选、对比、属性计算与个人记录可以单机完成。跨用户共享和跨设备同步需要后端，界面上的统计图不能冒充多人版本。

## 技术选型

HTML + CSS + 原生 JavaScript，无框架、无构建步骤、无运行时 CDN；经典脚本支持直接打开 `index.html`。

- `js/data/catalog.js`：从公开资料整理的本地只读数据。
- `js/data/challenges.js`：作者编排的只读参考队伍，与个人浏览器记录分开。
- `js/domain/rules.js`：纯计算函数，处理属性倍率、共享预算规则、队伍统计与配队任务条件。
- `js/data/store.js`：Promise 数据接口、账号、个人记录和输入校验，唯一读写 localStorage 的业务层。
- `js/ui/app.js`：渲染与事件处理，资料和个人记录均通过接口访问。
- `js/ui/lab-effects.js`：独立播放和取消实验室动效，照顾系统“减少动态效果”偏好，不保存记录或计算倍率。

未来联网时保持接口，替换数据层为后端请求；页面组织与属性计算继续使用。技术学习重点是数组、对象、事件、表单与存储，不堆叠框架。

## 风险与对策

- **外网不稳定**：开发时采集并缓存公开资料，记录版本，课堂运行使用本地快照。
- **题材认可度**：如实介绍角色资料与规则学习定位；收到明确课程意见再调整，不宣称已获批准。
- **版本混用**：使用同一快照的现行常规属性表，注明收录范围和规则口径。
- **预算与比较误解**：注明 3000 点属于项目自定挑战；展示平均能力与队伍人数，不把能力总和或防御统计解释为实战胜率。预算是否有趣需要真实试玩验证。
- **做不完或看不懂**：保住图鉴、筛选、详情和登录收藏；依次推迟属性练习、深入队伍分析和网络版，每段能运行且能解释。
- **记录丢失**：提供个人 JSON 备份与导入校验；数据只保存于当前浏览器和地址。
- **资料整理量大**：限定 151 只默认形态，第一版不同时扩展全部世代、招式和形态。

## 运行方式

直接用 Chrome / Edge 打开 `index.html`。推荐在项目根目录运行静态服务器：

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8080>，无需 npm 依赖。文件地址与 HTTP 地址的浏览器存储独立。

演示账号：`leaf` / `poke123`、`blue` / `poke123`，也可注册本地账号。登录用于展示个人记录隔离，请使用演示密码；它不提供服务端认证。
